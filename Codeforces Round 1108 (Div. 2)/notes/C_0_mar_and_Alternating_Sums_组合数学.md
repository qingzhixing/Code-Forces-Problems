# C. 0mar and Alternating Sums

## 题目信息

* **Clist Rating**: 1315
* **算法标签**：组合数学、数学、分类讨论、奇偶性

## 一句话题意

给定一个非递减数组，其中元素要么是 $-1$，要么是正整数，求交替和（$b_1 - b_2 + b_3 - \dots$）恰好为 $0$ 的子序列个数（包含空序列），结果对 $10^9 + 7$ 取模。

## 关键观察/转化

* **观察一：全正数非递减子序列交替和为 $0$，当且仅当每种数字都选了偶数个。**
* **证明**：设选出的正数子序列为 $b_1 \le b_2 \le \dots \le b_m$。
* 若 $m$ 为奇数，可将交替和重组为 $b_1 + (b_3 - b_2) + (b_5 - b_4) + \dots + (b_m - b_{m-1})$。由于 $b_1 \ge 1$ 且非递减性保证每个括号均 $\ge 0$，总和严格大于 $0$，不可能为 $0$。
* 若 $m$ 为偶数，可将交替和重组为 $(b_1 - b_2) + (b_3 - b_4) + \dots + (b_{m-1} - b_m)$。由非递减性知每个括号均 $\le 0$，因此总和为 $0$ 当且仅当每个括号都等于 $0$，即 $b_1 = b_2, b_3 = b_4, \dots, b_{m-1} = b_m$，等价于每种数值在子序列中均出现偶数次。
* **观察二：固定所有 $d$ 种不同元素的奇偶选择要求后，合法子序列数恒为 $2^{n-d}$。**
* **证明**：将原数组按相同值分成 $d$ 组，各组大小分别为 $c_1, c_2, \dots, c_d$（满足 $\sum_{i=1}^d c_i = n$）。
* 对任意大小为 $c_i \ge 1$ 的同值组，前 $c_i - 1$ 个元素均可任意选或不选（共 $2^{c_i - 1}$ 种选法），第 $c_i$ 个元素的选与不选唯一由该组所需的奇偶性决定（若前 $c_i - 1$ 个已满足奇偶性则不选，否则必选）。因此，无论该组要求选奇数个还是偶数个，方案数均恰好为 $2^{c_i - 1}$。
* 各组选择相互独立，由乘法原理，总方案数为 $\prod_{i=1}^d 2^{c_i - 1} = 2^{\sum_{i=1}^d c_i - d} = 2^{n - d}$。
* **观察三：含 $-1$ 时，额外合法情况仅对应“恰好一对相邻正整数 $(v, v+1)$ 与 $-1$ 均选奇数个，其余全选偶数个”。**
* **证明**：按子序列中 $-1$ 的个数奇偶性分类：
* **选偶数个 $-1$**：所有的 $-1$ 两两相消（$-1 - (-1) = 0$），问题退化为全正数情况，当且仅当所有数值（含 $-1$）均选偶数个。
* **选奇数个 $-1$**：$-1$ 两两相消后在最前面剩一个 $-1$。设后面选出的正数子序列为 $b_1 \le b_2 \le \dots \le b_m$，总交替和为 $-1 - b_1 + b_2 - b_3 + \dots = -1 - (b_1 - b_2 + b_3 - \dots)$。令其等于 $0$，等价于正数部分交替和 $b_1 - b_2 + b_3 - \dots = -1$。
* 由观察一的证明，若 $m$ 为奇数，正数部分交替和必 $> 0$，不可能等于 $-1$；故 $m$ 必为偶数，且 $(b_1 - b_2) + (b_3 - b_4) + \dots + (b_{m-1} - b_m) = -1$。
* 由于每个括号都是非正整数，其和为 $-1$ 当且仅当**恰好有一个括号等于 $-1$**（即某对相邻项满足 $b_{2k-1} = v, b_{2k} = v+1$），而其余所有括号都等于 $0$。翻译成奇偶性即为：$-1$、$v$、$v+1$ 这三组选奇数个，其余所有组选偶数个。
* **结论推导**：每种合法的奇偶分配状态互不重叠，且由观察二各贡献 $2^{n-d}$ 个子序列。设数组中同时出现 $v$ 和 $v+1$ 的对数为 $\ell$：
* 若数组中不含 $-1$，仅有“全偶”这 $1$ 种合法状态，答案为 $2^{n-d}$。
* 若数组中含 $-1$，有“全偶”的 $1$ 种状态加上 $\ell$ 对 $(v, v+1)$ 对应的 $\ell$ 种状态，共 $\ell + 1$ 种合法状态，答案为 $2^{n-d} \cdot (\ell + 1)$。

## 算法步骤

* 判断数组首位 `a[0]` 是否为 $-1$，记录数组中是否存在 $-1$。
* 利用数组非递减的性质直接原地去重，得到不同元素的个数 $d$。
* 用快速幂计算基础方案数 $2^{n - d} \bmod (10^9 + 7)$。
* 若数组中存在 $-1$，遍历去重后的相邻元素，统计满足 `a[i] + 1 == a[i + 1]` 的对数 $\ell$（数组中不含 $0$，无需对 $-1$ 特判），将答案乘以 $(\ell + 1)$ 并取模输出。

## 复杂度

* **时间复杂度**：$O(n)$（单组数据线性去重与扫描，快速幂 $O(\log n)$，总复杂度 $O(\sum n)$）
* **空间复杂度**：$O(n)

## 触发信号

* 题目给出**有序（非递减）数组**并求**交替和**为特定常数（如 $0$、$-1$）的子序列计数。
* 序列元素存在大量重复且要求统计子序列个数，暗示按**相同值分组**并利用“奇偶子集数均为 $2^{c-1}$”的对称性将计数简化为 $2^{n-d}$。
