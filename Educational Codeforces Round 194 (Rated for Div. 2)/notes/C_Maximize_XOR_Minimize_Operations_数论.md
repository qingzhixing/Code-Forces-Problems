# C. Maximize XOR, Minimize Operations

## 题目信息 (Problem Info)

* **Clist Rating**: 1263
* **算法标签**：位运算、贪心、数学（不变量）

## 一句话题意 (One-Sentence Summary)

给定非负整数 $x, y$，每次操作可将 $x$ 减 $1$ 同时将 $y$ 加 $1$（$x=0$ 时不可操作），求能达到的最大异或值 $x' \oplus y'$ 以及达到该最大值所需的最少操作次数。

## 关键观察/转化 (Key Observations/Transformations)

* **和守恒不变量**：每次操作一减一增，两数之和 $S = x + y$ 恒定不变；由于 $x$ 只能减小且非负，操作后的 $x'$ 可取 $[0, x]$ 内的任意整数，对应操作次数为 $x - x'$。
* **异或上界与无进位条件**：由 $x' + y' = (x' \oplus y') + 2(x' \mathbin{\&} y')$ 可知 $x' \oplus y' \le S$，取等充要条件是 $x' \mathbin{\&} y' = 0$；极端情况下令 $x'=0, y'=S$ 即可取等，故最大异或值恒为 $S = x + y$。
* **子掩码等价转化**：在 $x' + y' = S$ 的前提下，$x' \mathbin{\&} y' = 0$ 当且仅当 $x'$ 的二进制 `1` 是 $S$ 的二进制 `1` 的子集（此时 $y' = S - x'$ 无借位，恰好拥有其余的 `1`）。
* **按位贪心**：最小化操作数 $x - x'$ 等价于在 $S$ 的子掩码中找不超过 $x$ 的最大值 $x'$，利用高位权值大于所有低位之和的性质从高到低贪心选取即可。

## 算法步骤 (Algorithm Steps)

* 计算两数之和 $S = x + y$，这即为最大可能的异或值。
* 初始化目标值 $x' = 0$，从最高有效位（如第 $30$ 位）向第 $0$ 位倒序遍历二进制位 $i$。
* 若 $S$ 的第 $i$ 位为 `1`，且 $x' + 2^i \le x$，则将 $2^i$ 累加进 $x'$。
* 遍历结束后，输出最大异或值 $S$ 与最少操作次数 $x - x'$。

## 复杂度 (Complexity)

* **时间复杂度**：单组测试数据为 $O(\log(x + y))$（固定遍历约 $31$ 个二进制位），总时间复杂度为 $O(t \log(\max(x + y)))$。
* **空间复杂度**：$O(1)$（不计输入缓冲区的读取开销）。

## 触发信号 (Trigger Signals)

* 题目中出现“一个数减 $1$、另一个数加 $1$”**的操作 $\rightarrow$ 立即联想到**两数之和 $x + y$ 是不变量，将双变量操作转化为单变量区间 $[0, x]$ 上的取值问题。
* 涉及**同时出现加法（或固定和）与异或（XOR）求极值** $\rightarrow$ 立即写出恒等式 $a + b = (a \oplus b) + 2(a \mathbin{\&} b)$，检查无进位条件 $a \mathbin{\&} b = 0$（子掩码拆分）。
* 需要在某个数的二进制 `1` 子集中凑出**不超过上界 $U$ 的最大值** $\rightarrow$ 从高位到低位按位贪心试填。

## 算法证明

关于“**为什么从 $x+y$ 的二进制 `1` 中选子集凑出 $x' \le x$，就一定且只能这样凑出异或最大值 $x+y$**”，核心在于**和不变性**与**无进位/无借位加减法**的等价关系。

设初始和为 $S = x + y$。每次操作将 $x$ 减 $1$、$y$ 加 $1$，操作后的两数 $x', y'$ 始终满足**和守恒** $x' + y' = S$，且可达范围等价于任意满足 $0 \le x' \le x$ 的整数 $x'$（操作次数为 $x - x'$）。

由位运算恒等式：

$$
x' + y' = (x' \oplus y') + 2(x' \mathbin{\&} y')

$$

可知 $x' \oplus y' \le x' + y' = S$，当且仅当 **$x' \mathbin{\&} y' = 0$**（即 $x'$ 与 $y'$ 在二进制下没有任何一位同时为 `1`，相加不产生进位）时，等号成立，取到理论上界 $S$。由于至少可以取 $x' = 0, y' = S$（做 $x$ 次操作，此时 $0 \oplus S = S$），上界 $S$ **一定可达**。

在此基础上看子集构造的**必要性**与**充分性**：

* **必要性（为什么合法的 $x'$ 必须只能由 $S$ 中的 `1` 组成）**：
  若 $x' + y' = S$ 且 $x' \oplus y' = S$，则必有 $x' \mathbin{\&} y' = 0$。两个没有公共 `1` 的数相加不会产生任何进位，因此 $S = x' + y' = x' \mid y'$。这意味着：
* 若 $S$ 的第 $i$ 位是 `0`，则 $x'$ 和 $y'$ 的第 $i$ 位**都必须是 `0**`（否则按位或出来就是 `1`）；
* 若 $S$ 的第 $i$ 位是 `1`，则 $x'$ 和 $y'$ 在第 $i$ 位上**恰好一者为 `1`、一者为 `0**`。
  因此，任何能使异或值达到 $S$ 的 $x'$，其二进制中的 `1` **必然是 $S$ 中 `1` 的子集**（即 $x'$ 是 $S$ 的子掩码），同时受限于操作只能减小 $x$，必须满足 $x' \le x$。
* **充分性（为什么只要取 $S$ 中 `1` 的子集且 $x' \le x$，就一定能凑出 $x' \oplus y' = S$）**：
  任取 $S$ 的一个二进制子集构成 $x'$，并满足 $0 \le x' \le x$。我们执行 $x - x' \ge 0$ 次操作即可合法得到 $x'$，此时另一个数自动变为 $y' = S - x'$。
  因为 $x'$ 为 `1` 的位置在 $S$ 中也全为 `1`，计算二进制减法 $y' = S - x'$ 时**不会产生任何借位**——它等价于直接把 $S$ 中被 $x'$ 选走的那些 `1` 抹成 `0`，剩下的 `1` 全部留给 $y'$（即 $y' = S \oplus x'$）。
  由此直接保证 $x'$ 与 $y'$ 将 $S$ 的所有 `1` 完美划分成两个不相交集合（$x' \mathbin{\&} y' = 0$），故必有：

$$
x' \oplus y' = x' \oplus (S \oplus x') = S = x + y

$$

* **贪心最优性（为什么从高位到低位能保证操作数最少）**：
  操作数为 $x - x'$，最小化操作数即最大化满足 $x' \le x$ 的 $S$-子集 $x'$。由于二进制满足 $2^i > \sum_{j=0}^{i-1} 2^j$（任意一个高位 `1` 的权值严格大于所有低位 `1` 之和），从高位到低位枚举 $S$ 的每一个 `1`，只要加上 $2^i$ 不超过 $x$ 就果断选入，必然得到不超过 $x$ 的最大合法 $x'$。
