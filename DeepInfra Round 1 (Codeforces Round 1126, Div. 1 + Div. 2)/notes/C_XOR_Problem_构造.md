# C. XOR Problem

## 题目信息

题目链接：[codeforces.com/contest/2271/problem/C](https://codeforces.com/contest/2271/problem/C)

Clist Rating: 1386

算法标签：数论 构造 贪心

## 题目大意

给定一个整数 $n$，你需要构造一个数组 $a$，满足：

1. **每个元素都在 $0$ 到 $n$ 之间**，即 $0 \le a_i \le n$。
2. **在所有满足条件 1 的数组中，先让 beauty 最大，再让长度最大。**

数组的 **beauty** 定义为：

$$
\text{beauty}(a) = |a| - f(a)
$$

其中：

- $|a|$ 是数组的长度；
- $f(a)$ 是数组中**异或和为 $0$ 的非空子数组个数**。

## 关键观察

- 若 [L, R] 异或和为 0，则说明对其前缀异或和数组：s[L - 1] = s[R];
- 考虑相同的前缀和值：当相同数目 = 1 时，beauty = 1 - 0 = 1; 数目 = 2 时，beauty = 2 - 1 = 1; 数目 >=3 时，beauty <= 0；也就是说如果我们希望达到最大beauty，**相同前缀异或和只能出现 1 or 2 次** ，同时我们要使得长度最长，所以**相同前缀异或和需要仅出现两次**。

## 算法思路

首先构造前缀异或和，再还原出原数组。

### 构造前缀异或和的方法

- 令 x = $2^{\lfloor \log_2{n} \rfloor}$, 所以 x <= n < 2x ;
- 将前缀异或和分为两组，一组是 [0, x - 1], 一组是 [x, 2x -1] ;
- 将每组正序和负序拼接，然后不同组之间也拼接起来，这样就能构成目标前缀异或和数组。

### 为什么要这样构造异或前缀和

a[i] = s[i] ^ s[i+1]

- 考虑第一组 [0, x - 1]，每个元素 msb < x，也就是说组间相邻异或和 a[i] = s[i] ^ s[i+1] < x <= n，符合要求；
- 考虑第二组 [x, 2x - 1]，其最高位为 x，相邻两项异或时会抵消最高位，最后的值也 <x <=n，符合要求；
- 所以唯一不符合要求的情况只能是两组交界处。我们已知 0 ^ x = x <= n，所以我们把 0 放在第一组最后面，x放在第二组最前面。

最终能得出我们的构造方法。

## 复杂度

时间复杂度：$O(n)$

空间复杂度: $O(n)$

## 触发点

- **区间异或为 0 → 前缀异或配对**
- **按最高位分组构造，保证相邻异或 ≤ n**
