# E. Prime Destruction

## 题目信息

Clist Rating: 1453

算法标签：暴力枚举 DP 数论 数学

## 题目大意

给定一个正整数数组 a，长度为 n。一次操作允许选取其中一个元素 x， x >1，取 x 一个素因子 p，从数组中删掉当前元素，在 a 中新加入 p 个 x / p。

再给定一个数 k ，求使得所有元素都 <= k 时的操作次数。

## 算法思路

这题是递归分解，有比较明显的计数类DP。

1. 初始化 埃氏筛初始化 2 ~ MAX_M 的质因子。
2. 令 dp [i] 表示 将数字 i 变为 <= k 的最小代价。
3. dp[1 ~ k] = 0;
4. dp[i], k < i <= MAX_M, dp[i] = min{1 + p * dp[i / p]};
5. 答案为 a 中数字的 dp 和。

## 触发点

* 递归分解结构，可以想到记忆化搜索 或者 DP。
