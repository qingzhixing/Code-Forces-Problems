# C. I Know About a Million Things

## 题目信息

题目链接：[https://codeforces.com/contest/2261/problem/C](https://codeforces.com/contest/2261/problem/C%E2%80%B8)

算法标签：博弈论 数学

## 题目大意

M 和 L 在玩一个游戏，从一个长度为 n 的数组中删除一些数字，删到没法删位置，无法行动的人输。

删除条件满足其一：

1. 删除一个
2. 删去的数字总和为偶数

## 我的思路

- 必输态：一奇一偶
- 必赢态：奇数个数 %2 ==0

## 卡点

翻笔记来总结的，当时就是没想完，还有情况没覆盖到。

## 关键观察

(i, j) 表示还剩下 i 奇数，j 偶数

- 必输态 (0, 0)
- 必输态 (1, 1)
- 必输态(3, 0)

剩余都是必赢态。

## 算法思路

1. 对于 i == 0，可以一次取完所有偶数数，对手必输。
2. 对于 i != 0, i % 2 == 0，可以一次取完所有数字，和为偶数，对手必输。
3. 对于 i == 1, j == 0，可以取最后一个数字，对手无数字。
4. 对于 i == 1, j > 1，可以取成 (1, 1)，留给对手必败态
5. 对于 i == 3, j > 0，可以取成 (3, 0)， 留给对手必败态。
6. 对于 i % 2 != 0, i > 3, 可以取成 (3, 0),，留给对手必败态。

所以只要判断初始状态是不是 (1, 1) 或者 (3, 0) 即可知道必胜还是必败
