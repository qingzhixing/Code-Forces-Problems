# B. Diverse String

## 题目信息 (Problem Info)

* **Clist Rating**: 1035
* **算法标签**：组合数学、贪心、子序列双射、凸函数极值、打表找规律

## 一句话题意 (One-Sentence Summary)

给定一个长度为 $n$ 的 `01` 字符串，你最多可以先翻转其中 $k$ 个字符；字符串的多样性定义为“将至多一个连续子串全部置为 `0` 或全部置为 `1`”所能得到的不同字符串总数，求翻转后能达到的最大多样性。

## 我的第一思路 (Initial Approach)

* 如果不 op，还有对每个数位单独 op，那么至少能产生 n+1 个新串，ans >= n+1
* 模拟样例得到猜想，也许最多连续越多越好。
* 全 1 数列将产生 n*(n+1)/2 + 1 种方案
* 考虑新增 0 的时候就卡住了，不知道怎么办，而且还有 k 个数要翻转，变量太多了没思路。
* 之后暴力枚举发现答案与01位置无关且答案等于 ``cnt0 * (cnt0 + 1) / 2 + cnt1 * (cnt1 + 1) / 2 + 1``

## 关键观察/转化 (Key Observations/Transformations)

* **从“数操作区间”转化为“数真正改变的位置”（子序列双射）**：不要看你选了哪个 $[l, r]$，而是对比操作前后的字符串**究竟有哪些位置发生了改变**：
* 若执行置 `1` 操作（$x = 1$）且字符串确实发生了变化，那么原串中被变成 `1` 的那些 `0`，在**原串所有 `0` 抽出来的子序列**中必然构成一段**非空连续子段**。反之，任取 `0` 子序列中的一段连续区间（比如从第 $i$ 个 `0` 到第 $j$ 个 `0`），只需在原串中取第 $i$ 个 `0` 的下标作为 $l$、第 $j$ 个 `0` 的下标作为 $r$ 执行置 `1`，就能精准只把这一段 `0` 变成 `1`（中间夹杂的 `1` 被置 `1` 后保持不变）。因此，所有能使字符串改变的置 `1` 结果与 `0` 子序列的非空连续子段**一一对应**，方案数为 $T(z) = \frac{z(z+1)}{2}$。
* 同理，所有能使字符串改变的置 `0`（$x = 0$）结果与 `1` 子序列的非空连续子段**一一对应**，方案数为 $T(o) = \frac{o(o+1)}{2}$。
* **利用字符计数证明不重不漏**：原串本身有 $z$ 个 `0`（贡献 $1$ 种）；有效的置 `1` 操作会使 `0` 的个数严格减少（$< z$）；有效的置 `0` 操作会使 `0` 的个数严格增加（$> z$）。三类结果中 `0` 的数量互不相交，绝不可能产生重复字符串，故总多样性恒为 $1 + T(z) + T(o)$，彻底与字符排列顺序脱钩。
* **凸函数极值决定贪心方向（马太效应）**：由于 $z + o = n$ 恒定，设多数字符有 $x$ 个、少数字符有 $y$ 个（$x \ge y$）。每将一个少数字符翻转为多数字符，$T(x)$ 增加 $x + 1$，而 $T(y)$ 仅减少 $y$，净增量为 $(x + 1) - y > 0$（即便初始 $x = y$ 翻转一次也能净增 $1$）。因此两个字符数量差距越悬殊，多样性越大，最优策略就是把少数字符尽可能多地翻成多数字符。

## 算法步骤 (Algorithm Steps)

* 遍历字符串 $s$，分别统计初始 `0` 的个数 `cnt0` 和 `1` 的个数 `cnt1`。
* 确定当前的多数字符数量 $x = \max(\text{cnt0}, \text{cnt1})$，利用至多 $k$ 次翻转机会将少数字符并入多数字符，得到最终多数字符的最大可能数量 $X = \min(n, x + k)$，少数字符剩余数量为 $Y = n - X$。
* 使用 64 位整数计算并输出最终答案 $1 + \frac{X(X+1)}{2} + \frac{Y(Y+1)}{2}$。

## 复杂度 (Complexity)

* **时间复杂度**：单组测试数据 $\mathcal{O}(n)$，仅需线性扫描一遍字符串统计字符频数；总体时间复杂度为 $\mathcal{O}(\sum n)$。
* **空间复杂度**：$\mathcal{O}(n)$，用于存储输入的字符串数组（若直接对字节切片 `&[u8]` 统计，可降至严格 $\mathcal{O}(1)$ 额外空间）。

## 我的卡点与易错点 (Common Pitfalls & Mistakes)

* **陷入原下标的边界去重泥潭**：容易去想“如果 $s_l$ 已经是 $x$ 该怎么排除重复”，导致推不出式子。应当切换视角，直接建立“最终不同结果”与“被修改元素的集合”之间的一一映射。

## 触发信号 (Trigger Signals)

* **“执行至多一次区间操作，求能得到多少种不同结果”**：看到对结果去重计数，立刻放弃枚举操作参数 $(l, r)$，转而思考“原串与结果串的差异集合长什么样”，寻找差异集合与子序列连续段、前缀/后缀之间的双射。
* **目标函数形如 $\sum c_i^2$ 或 $\sum \frac{c_i(c_i+1)}{2}$ 且总和 $\sum c_i = n$ 固定**：平方和与三角数具有严格凸性——求**最大值**永远是“劫贫济富”（让最大项尽可能吞并其他项，越极端越好）；求**最小值**永远是“削峰填谷”（让各项尽可能平均分配）。
* **操作代价复杂但数据范围要求 $\mathcal{O}(n)$ / $\mathcal{O}(1)$ 公式解**：考场上 10 分钟内若找不到切入点，果断像本题一样用 `Set` 写暴力模拟打表，优先检验**答案是否与元素位置无关（仅依赖频数/奇偶性/极值）**。
