# D. Good Pair Queries

## 题目信息

* **Clist Rating**: 1436
* **算法标签**：前缀和、贪心、构造、数学推导、不变量/势能分析

## 一句话题意

给定两个长度为 $n$ 的 01 串 $s$ 和 $t$，多次独立查询区间 $[l, r]$，判断能否通过若干次操作将对应的两段子串同时删空：每次操作任选一个非空下标集合，要求存在字符 $c \in \{\texttt{0}, \texttt{1}\}$ 同时作为两个子串在所选位置上的众数（出现次数 $\ge \lceil k/2 \rceil$），随后删去这些位置。

## 我的第一思路

想到用前缀和统计 01 出现次数来快速处理区间查询，并按列将位置分类：发现 $s_i = t_i$ 的列（即 `(0,0)` 和 `(1,1)`）一定能删除，而 `(0,1)` 和 `(1,0)` 这类不同列需要借助 `(0,0)` 或 `(1,1)` 才能删去。

## 关键观察/转化

* **按列分类与顺序无关**：操作只依赖所选位置集合中字符的频次，与字符顺序无关。可将每个位置视为一列 $(s_i, t_i)$，统计区间内四种列的个数：相同列 $u = N(0,0), v = N(1,1)$，不同列 $x = N(0,1), y = N(1,0)$。
* **充要条件**：区间合法当且仅当 $\vert{}x - y\vert{} \le u + v$。
* **充分性（极小操作构造）**：`(0,1)` 与 `(1,0)` 可直接两两配对互相消去（拼成 `01` 与 `10` 时，`0` 和 `1` 均为共同众数）；配对完后剩余的 $\vert{}x - y\vert{}$ 个同类型不同列，再逐一与相同列配对删除；最后剩余的相同列均可单独删除。
* **必要性（势能/不变量分析）**：定义势能 $\Phi = \vert{}x - y\vert{} - (u + v)$。对任意一次合法操作，无论选定共同众数为 `0` 还是 `1`，由众数定义均可推导出 $\vert{}x_0 - y_0\vert{} \le u_0 + v_0$；结合三角不等式可知每次操作后 $\Phi$ 单调不减，由于删空时 $\Phi = 0$，故初始必满足 $\Phi \le 0$。
* **前缀和降维**：无需分别维护 4 个计数，只需维护相同列总数 $u + v$ 与不同列差值 $x - y$ 这 2 个前缀和即可。

## 算法步骤

* 遍历字符串预处理前缀和 `same[i]`，记录前 $i$ 位中满足 $s_i = t_i$ 的位置数量（对应 $u + v$）。
* 同步预处理前缀和 `diff[i]`，记录前 $i$ 位中 `(0,1)` 减去 `(1,0)` 的数量差（对应 $x - y$，可直接累加 `t[i] - s[i]`）。
* 对每次查询 $[l, r]$，利用前缀和差分在 $O(1)$ 时间内求出区间内的 $uv$ 与 $xy$。
* 判定 $\vert{}xy\vert{} \le uv$ 是否成立，成立则输出 `YES`，否则输出 `NO`。

## 复杂度

* **时间复杂度**：$O(n + q)$，每组测试数据预处理 $O(n)$，单次查询 $O(1)$。
* **空间复杂度**：$O(n)$，用于存储输入字符串与前缀和数组。

## 我的卡点与错误点

* 最初以为 `(0,1)` 和 `(1,0)` 都必须依赖 `(0,0)` 或 `(1,1)` 才能删除，遗漏了 `(0,1)` 和 `(1,0)` 之间可以直接两两配对抵消的情况，导致差一步未能推出完整的充要条件 $\vert{}x - y\vert{} \le u + v$。

## 触发信号

* **任意选子序列/位置集合 + 频次（众数）限制**：说明顺序无关，应直接将双串按列归类并统计各类频次。
* **多次独立区间判定查询**：通常存在关于各类计数的简洁充要不等式，结合前缀和即可 $O(1)$ 回答。
* **单次操作规模不限（可一次删任意多元素）**：优先尝试仅用大小为 1 或 2 的极小操作构造充分性，再通过势能函数/不变量证明大集合操作无法超越该界限。
