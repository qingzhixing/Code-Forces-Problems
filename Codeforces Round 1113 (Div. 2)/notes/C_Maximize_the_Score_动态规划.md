# C. Maximize the Score

## 题目信息

* **Clist Rating**: 1293
* **算法标签**：动态规划、贪心、性质观察

## 一句话题意

给定一个长度为 $2n$ 的数组，其中 $1$ 到 $n$ 每个数恰好出现两次。每次操作可以选择一个数 $x$，删除其在当前数组中最左和最右出现位置之间的整段子数组（假设长度为 $L$），获得 $L^2$ 的得分并将剩余元素拼接，求清空数组能获得的最大总得分。

## 关键观察/转化

* **平方和不等式消除嵌套操作**：对于任意正整数 $a, b$，恒有 $(a + b)^2 > a^2 + b^2$。如果先删除一个内部子段（得分为 $a^2$），再删除包含它的外部子段（得分为 $b^2$），总得分为 $a^2 + b^2$；而如果直接一次性删除外部子段，得分为 $(a + b)^2$，严格更优。
* **转化为不相交区间划分**：由于嵌套删除（先删内部使其拼接缩水，再删外部）永远不如直接删除外部原区间划算，最优策略中所有产生大于 $1$ 长度贡献的操作，必然对应**原数组中互不相交的连续子数组**。
* **两类基础转移**：原数组中的每个位置 $i$，要么单独作为一个长度为 $1$ 的元素被消去（贡献 $1^2 = 1$ 分），要么作为某个数字 $a_i$ 的第二次出现，与它的第一次出现位置 $prev[a_i]$ 直接构成闭区间 $[prev[a_i], i]$ 整体一次性消除（贡献 $(i - prev[a_i] + 1)^2$ 分）。

## 算法步骤

* 定义状态 $dp[i]$ 表示处理完原数组前缀 $1 \dots i$ 所能获得的最大得分，初始化 $dp[0] = 0$。
* 维护一个数组 $prev$，用于记录每个数字第一次出现的下标。
* 从 $1$ 到 $2n$ 遍历数组位置 $i$：
* **决策一（单点消除）**：当前元素单独消除，状态转移为 $dp[i] = dp[i - 1] + 1$。
* **决策二（区间消除）**：若 $a_i$ 之前已经出现过（设第一次出现位置为 $p = prev[a_i]$），则可以将区间 $[p, i]$ 一次性消除，状态转移为 $dp[i] = \max(dp[i], dp[p - 1] + (i - p + 1)^2)$；若 $a_i$ 是第一次出现，则记录 $prev[a_i] = i$。
* 遍历结束后，$dp[2n]$ 即为最大可能得分。

## 复杂度

* **时间复杂度**：$\mathcal{O}(n)$。每个测试样例只需线性扫描一遍长度为 $2n$ 的数组，状态转移为 $\mathcal{O}(1)$。
* **空间复杂度**：$\mathcal{O}(n)$。需要长度为 $2n + 1$ 的 `dp` 数组和长度为 $n + 1$ 的 `prev` 数组。

## 触发信号

* 题目涉及**区间消除并拼接剩余元素**，且收益函数为区间长度的**凸函数**（如 $L^2$）。
* 看到凸函数收益（满足 $f(a + b) > f(a) + f(b)$）时，优先思考是否可以**贪心排除内部嵌套删减操作**，从而将动态变化的数组消除问题退化为静态原数组上的**不相交区间线性 DP**。
