# B. Frogs Jump

## 题目信息

链接：[https://codeforces.com/contest/2272/problem/B](https://codeforces.com/contest/2272/problem/B%E2%80%B8)

Clist Rating: 1011

算法标签：贪心 构造

## 题目大意

### 场景

一个 2 × n 的网格，每列至少一只青蛙。先删掉最少的青蛙（k 只），让剩下的青蛙同时跳一步（上下左右），要求跳完后 **每行、每列的青蛙总数都不变** ，求最小的 k。

## 我的思路

- 观察到，要保持每行每列在跳跃前后不变，那么：

  - 水平跳跃时，跳跃必须左右交换。
  - 竖直跳跃时，向上跳的总数必须等于向下跳的总数。
- 把每一列压缩成 `frogs[i] ∈ {0,1,2}`，然后从左到右扫描做局部配对：

  - `1` 和相邻的 `1` 配一对；
  - `2` 自己上下配，或和 `0` 配；
  - 配不上的 `1` 删掉，计入答案。

### 关键错误点:

1. 我这里把 2 当做了不可拆分的整体，忽略了 1 2 1 这样的匹配，2可以被拆分成两个 1 和左右分别匹配。
2. 并且实际上也没有 0 这种情况，因为每列必须要有一只青蛙。

## 关键观察与转化

- **合法方案 ⇔ 所有青蛙能两两配对。**
  每次跳动都必须有反向跳抵消（否则行/列计数变），所以 **青蛙必须成对**；每对的两只位于 **同列或相邻列** （列差 ≤ 1）即可合法对跳。
- **偶数只青蛙的跳法一定成立(k=0)** **因为 每列至少一只，所以排序后序列相邻两只列差 ≤ 1，所以能配对**
- 奇数只青蛙的删法：若有列为 2，则从中删一只，这样能保留每列至少一只的性质。所有列都为 1，则删首尾任意一个。

## 算法步骤

只需要判断青蛙奇偶性即可得出删除数量，不用输出如何删除。

```Rust
fn solution(tokens: &mut SplitAsciiWhitespace) {
    let _n: usize = next(tokens);
    let line1 = next_str(tokens);
    let line2 = next_str(tokens);
    let total = line1.into_iter().filter(|&ch| ch == 'f').count()
        + line2.into_iter().filter(|&ch| ch == 'f').count();
    println!("{}", total % 2);
}
```
