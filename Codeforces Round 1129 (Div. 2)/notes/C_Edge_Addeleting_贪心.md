# C. Edge Addeleting

## 题目信息

题目链接: [https://codeforces.com/contest/2277/problem/C](https://codeforces.com/contest/2277/problem/C)

Clist Rating: 1241

算法标签: 贪心 树形结构 DFS 图论

## 大致题意

连接根节点和某些节点，再删去环上一条边，使得根节点到编号最大的节点距离最长

## 我的思路

- 首先，如果距离已经是理论最长，即 n - 1，则直接输出答案，任何操作不可能使答案变小。
- 对于节点 v, v 到 1 的路径跟 n 到 1 的路径没有重边时，对该点的任何操作对答案无影响。
- 当保留 (1, vi) 这条边时，应该删除 vi 到 1 路径上连向 1 的最后一条边.

> 这一步推错了， 实际上要删除 n -> 1 路径上离 1 最近的那条边
> 不过当时想到是添加 1 -> vi 这条边之前的路径的那条边，其实也等价于 n -> 1 的边了，因为 i 和 n 路径有共边

- 当 vi 对答案无影响时保留 (1, vi) 没有意义。

## 关键观察

- 1 -> n 路径中，最多能多连 dist(1, n) 条边。
- 当我们保留第一次 vi 时，删去了离 1 最近的那条边，此时 vi 成为 n -> 1 通路上唯一连向 1 的边。当我们保留第二个 vj 时，上一次保留的边将会被删除。也就是说，**我们最多只能保留一个 vi。**
- 与答案无关的点的共同点：**n -> vi 的路径上经过了 点1**

## 算法步骤

1. 定义 dist[i] 表示 n -> i 的距离。
2. 如果 i 无影响，则 dist[i] 为初始值 -1.
3. dist[n] = 0;
4. 从 n 开始BFS，求各个点到 n 的距离，并且不扩展 点1，这样无影响的点 dist[i] == -1;

> 保留一个 i 节点对 n -> 1 长度影响：路径长度变为 `1 + dist[i]` ( 先走到 i, 再走到1 )

5. 我们只能保留一个节点，所以答案为 `max{ dist[1], 1 + dist[i] }`

## 复杂度

时间复杂度: O(n)

空间复杂度: O(n)
