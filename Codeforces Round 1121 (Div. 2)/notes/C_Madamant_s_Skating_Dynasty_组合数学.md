# C. Madamant's Skating Dynasty

## 题目信息 (Problem Info)

* **Clist Rating**: 1333
* **算法标签**：组合数学、算贡献、排序、前缀积与后缀积、后缀和、树论

## 一句话题意 (One-Sentence Summary)

给定 $n$ 个权值互不相同的有标号节点，构建有根树使得每个非根节点的父节点权值严格大于它自身，定义树的代价为所有边的父子权值差之和，求所有合法有根树的代价总和（对 $998\,244\,353$ 取模）。

## 关键观察/转化 (Key Observations/Transformations)

* 设权值数组为 a,将 a 从小到大排序之后，a[n] 一定是树根。
* 共有 n-1 个节点需要确定父节点。对于下标为i的节点，一共有 n-i 种父节点选择方式，在它后面的所有节点都可以成为它的父节点。
* 一个合法的树就是每个i都向右选择了一个父节点，一共有 (n-1)!种选择。
* 我们没法直接枚举出选择方式，我们可以尝试固定一条边，计算它的贡献。对于确定的节点 i，选择一个父节点 j，i->j这条边被确定下来，其他点可任意选，还有 W = `(n-1)!/n-1-i`种选法。这条边的贡献就是 `(a[j] - a[i]) * W`
* W 仅与 i 相关，可以记为 Wi，我们可以将i 的所有边统一起来，节点i的贡献就是$\sum_{j=i+1}^{n-1} [Wi * (aj - ai)]$ = $ Wi *\sum_{j=i+1}^{n-1} (aj - ai)$ = $Wi * [suffix_sum_{i+1} - a_i*(n - 1 - i)]$

## 算法步骤 (Algorithm Steps)

* 特判 **$n = 1$** 时直接输出 `0`；否则将数组从小到大不稳定排序（`sort_unstable`），排序完成后再将所有元素对 `MOD` 取模。
* 令 **$m = n - 1$**，预处理 **$1 \dots m$** 的前缀阶乘 `fact_prefix[k]`（表示 **$1 \times \dots \times k$**）和后缀阶乘 `fact_suffix[k]`（表示 **$k \times \dots \times m$**，边界 `fact_suffix[m + 1] = 1`）。
* 初始化答案 `result = 0` 以及右侧元素后缀和 `suffix_sum = a[n - 1]`，按位置下标 **$i$** 从 **$m - 1$** 倒序枚举至 **$0$**。
* 对每个节点 **$i$**，计算其可选父节点数 **$k = m - i$**，由 `choice = fact_prefix[k - 1] * fact_suffix[k + 1] % MOD` 得到包含某条边的树数量，再结合 `suffix_sum` 算出差值和 `(suffix_sum + MOD - a[i] * k % MOD) % MOD`，乘上 `choice` 累加进 `result`，最后将 `a[i]` 并入 `suffix_sum`。

## 触发信号 (Trigger Signals)

* **“树上父节点权值严格大于/小于子节点” + “合法有根树计数”**：立刻先**排序**，将有根树的无环连通约束转化为每个节点在序列单侧独立选父节点的组合模型。
* **“求所有合法图/树结构的边权代价总和”**：典型的算贡献（Contribution Technique）信号，拆开求和号，转为统计“单条边（或单个点）的代价 $\times$ 包含它的合法方案数”。
* **“求除去某一项后的全局乘积（且不想写逆元）”**：维护**前缀积 + 后缀积**，用两端乘积拼接直接绕开模除法。
