# C. Rank Subsequence

## 题目信息

* **Clist Rating**: 1279
* **算法标签**：枚举、贪心、子序列

## 一句话题意

从长度为 $n$ 的序列中选出一个尽可能长的子序列（设长度为 $m$），要求子序列中第 $j$ 个位置上的元素（原下标为 $i$）同时满足左排名 $j \notin [l_i, r_i]$ 且右排名 $m - j + 1 \notin [u_i, v_i]$。

## 关键观察/转化

* i 是否能在 j 位置，与 j 和 m 有关。由于 m 不确定，没办法确定是否能放。
* 注意到 n <= 5e3，n^n <= 3e7，我们可以从 n 到 1 枚举 m，再从前往后，枚举每个 i，判断是否能填入，如果能填就贪心填入。
* 这个贪心总是能找到最优解，因为在第 j 位贪心选择了 x，某个最优解选择 y，pos x < pos y，让这个最优解选择 x，其一定也是满足答案的，并且后续元素顺序不会被改变。并且选的越靠前，后续就有越多元素可供选择。所以贪心能找到最优答案。

## 算法步骤

* 将目标子序列长度 $m$ 从 $n$ 到 $1$ 倒序枚举。
* 对于固定的 $m$，维护当前待填充的位置 $j = 1$，从左到右线性扫描原序列的每个元素 $i$。
* 检查元素 $i$ 放在位置 $j$ 是否同时满足 $j \notin [l_i, r_i]$ 与 $m - j + 1 \notin [u_i, v_i]$；若满足则立刻选取，并令 $j \leftarrow j + 1$。
* 若 $j$ 成功超过 $m$，说明长度 $m$ 可行，直接输出 $m$ 并结束；若枚举完仍无解，则输出 $0$。

## 复杂度

* **时间复杂度**：单组测试最坏 $O(n^2)$，所有测试点总计 $O(\sum n^2) \le O((\sum n)^2)$。
* **空间复杂度**：$O(n)$，仅需存储每个元素的限制区间。

## 触发信号

* 判定条件同时依赖“当前位置”和“最终总长度/总数”等全局未知量，且答案不具备二分单调性时，考虑**直接枚举该全局量**以消除耦合。
* 题目给出 $\sum n \le 5000$，高度暗示 $O(n^2)$ 做法（常见结构为“外层枚举 + 内层 $O(n)$ 贪心验证”）。
* 固定参数后，问题转化为按顺序挑选指定长度的子序列，且早选只会扩大后续可选范围时，优先尝试“能选就立刻选”的贪心策略。
