# B. String Construction

## 题目信息 (Problem Info)

* **Clist Rating**: 894
* **算法标签**：构造、贪心、字符串

## 一句话题意 (One-Sentence Summary)

构造一个长度为 $n$ 的 $01$ 字符串，使得 $0$ 和 $1$ 的数量之差不超过 $1$，且相邻相同字符的对数恰好为 $k$；若无法构造则输出 $-1$。

## 关键观察/转化 (Key Observations/Transformations)

* **等价转化（相邻相同对数 $\leftrightarrow$ 极长连续相同子段数）**：长度为 $n$ 的字符串共有 $n-1$ 个相邻位置。每有 $1$ 对相邻不同字符，就会产生一个分段边界。因此，若恰好有 $k$ 对相邻相同字符，则必然有 $(n-1) - k$ 对相邻不同字符，整个字符串会被划分为 $segment = (n-1) - k + 1 = n - k$ 个极长连续的 $0/1$ 交替块。
* **可行性边界**：当 $segment \le 1$（即 $k = n - 1$）时，整个字符串只能由同一种字符组成（全 $0$ 或全 $1$）。由于题目给定 $n \ge 2$，此时 $0$ 和 $1$ 的数量差为 $n \ge 2 > 1$，必定无解。
* **平衡度保持**：当 $segment \ge 2$ 时，我们可以先用长度为 $1$ 的交替字符填满前 $segment - 2$ 个块（它们的 $0$ 和 $1$ 数量之差不超过 $1$），然后把剩余需要凑够的 $k$ 个重复字符**平分给最后两个不同字符的块**（一个块分 $\lfloor k/2 \rfloor$ 个，另一个块分 $\lceil k/2 \rceil$ 个）。这样两个不同字符各自增加的数量之差最多为 $1$，完美保证最终总数量之差不超过 $1$。

## 算法步骤 (Algorithm Steps)

1. 计算交替块的数量 $segment = n - k$；若 $segment \le 1$，直接输出 `-1` 并返回。
2. 将前 $segment - 2$ 个块设为单个字符，按 `0101...` 交替输出。
3. 将多出来的 $k$ 个字符平分到最后两个块上：倒数第二个块额外重复 $k - \lfloor k/2 \rfloor$ 次，最后一个块额外重复 $\lfloor k/2 \rfloor$ 次，从而维持 $0$ 和 $1$ 的数量平衡。

## 复杂度 (Complexity)

* **时间复杂度**：$\mathcal{O}(n)$，单组测试数据只需线性构造并输出长度为 $n$ 的字符串，总时间复杂度 $\mathcal{O}(\sum n)$。
* **空间复杂度**：$\mathcal{O}(n)$（取决于输入缓冲及字符串重复分配开销，若直接输出或复用缓冲区可优化至 $\mathcal{O}(1)$ 额外空间）。
