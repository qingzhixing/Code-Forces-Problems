# C2. Marenol (hard version)

## 题目信息 (Problem Info)

* **Clist Rating**: 1148
* **算法标签**：不变量分析、奇偶性、模 3 同余、思维、构造与贪心

## 一句话题意 (One-Sentence Summary)

给定两个等长的 `01` 串 $a$ 和 $b$，每次操作可以将子串 `001` 与 `100` 互换，或将 `110` 与 `011` 互换，求将 $a$ 变为 $b$ 的最少操作次数（若不可达则输出 `-1`）。

## 关键观察/转化 (Key Observations/Transformations)

* **交替串死锁特判**：操作的前提是存在至少两个相邻的相同字符（即 `00` 或 `11`）。若字符串形如 `010101...` 或 `101010...`，则无法进行任何操作；此时只有 $a = b$ 答案为 $0$，否则直接为 $-1$。
* **下标模 3 的奇偶差分不变量**：观察单次操作对字符下标（模 $3$ 意义下）的影响：
* `001` $\leftrightarrow$ `100`：相当于把一个 `1` 的位置移动了 $2$ 格（模 $3$ 下从一个剩余类跳到另一个剩余类），而其余位置的 `1` 不变。更本质地看，把所有操作统一看作**下标模 $3$ 的三元组统计**：设 $c_r$（$r \in \{0, 1, 2\}$）为串中满足 $i \bmod 3 = r$ 且 $s_i = \texttt{1}$ 的位置个数。
* 在 `001` $\leftrightarrow$ `100` 中，某两个模 $3$ 余数类的 `1` 数量一个 $+1$、一个 $-1$，第三个不变；但对于 `110` $\leftrightarrow$ `011`，同样是把一个 `0` 移动 $2$ 格，等价于某两个模 $3$ 余数类的 `1` 数量一个 $+1$、一个 $-1$（因为 `110` 占了三个不同模 $3$ 余数位置中的两个 `1`，变成 `011` 后，原本是 `1` 的某个余数变成了 `0`，原本是 `0` 的余数变成了 `1`）！
* **核心惊人结论**：无论是哪种操作，效果**完全等价于**：在模 $3$ 的三个余数桶 $(c_0, c_1, c_2)$ 中，将一个桶的 `1` 的个数 $-1$，另一个桶的 `1` 的个数 $+1$（即**一个 `1` 在数组中跨过 2 个位置移动，或者等价于相邻 `1` 的转换**）！Wait——让我们精确核对单次操作的变化量！
* 精确核对（下标从 $0$ 开始，考察连续三个位置 $i, i+1, i+2$，它们的模 $3$ 余数互不相同）：
* `001` $\leftrightarrow$ `100`：位置 $i$ 和 $i+2$ 上的 `1` 发生了交换！即 $c_{i \bmod 3}$ 与 $c_{(i+2) \bmod 3}$ 其中一个 $+1$，另一个 $-1$；**`1` 的总数 $c_0 + c_1 + c_2$ 不变**！Wait：`110` $\leftrightarrow$ `011` 呢？位置 $i, i+1$ 是 `1`，变成位置 $i+1, i+2$ 是 `1`，**依然是位置 $i$ 的 `1` 移到了位置 $i+2$**（即 $s_i$ 和 $s_{i+2}$ 交换，前提是中间的 $s_{i+1}$ 与被移动的另一端配合：当 $s_i \neq s_{i+2}$ 时，无论 $s_{i+1}$ 是 `0` 还是 `1`——若 $s_i=\texttt{0}, s_{i+2}=\texttt{1}$，当 $s_{i+1}=\texttt{0}$ 时是 `001`$\to$`100`，当 $s_{i+1}=\texttt{1}$ 时是 `011`$\to$`110`）！
* **终极简化（奇偶位置独立交换 / 冒泡排序）**：
* 观察上述核对结果：只要 $s_i \neq s_{i+2}$，无论中间的 $s_{i+1}$ 是 `0` 还是 `1`：
* `0` + `0` + `1` = `001` $\to$ `100`
* `0` + `1` + `1` = `011` $\to$ `110`
* `1` + `0` + `0` = `100` $\to$ `001`
* `1` + `1` + `0` = `110` $\to$ `011`
* **全部四种合法操作合并为一句话**：**你可以任意交换距离为 2 的两个不同字符（即交换 $s_i$ 和 $s_{i+2}$，当 $s_i \neq s_{i+2}$ 时）！**
* 这意味着：**奇数下标子序列**与**偶数下标子序列**完全独立！每次操作就是在奇数位子序列内部交换两个相邻的不同字符，或者在偶数位子序列内部交换两个相邻的不同字符！
* **最少操作次数转化为逆序对/位置差的绝对值之和**：
* 在奇数位（或偶数位）子序列内部，每次操作等价于相邻元素交换（由于相同元素无需交换，任意重排的最小相邻交换次数就是 `1` 的目标位置与初始位置在子序列内下标差的绝对值之和）。
* 可行性充要条件：$a$ 和 $b$ 在**偶数下标上的 `1` 的个数相同**，且在**奇数下标上的 `1` 的个数相同**！
* 最少操作次数：将偶数下标抽出来，设 $a$ 中偶数位 `1` 的位置列表为 $p_1, p_2, \dots, p_k$，$b$ 中偶数位 `1` 的位置列表为 $q_1, q_2, \dots, q_k$，则偶数位的最少交换次数为 $\sum_{j=1}^k \frac{\vert{}p_j - q_j\vert{}}{2}$；奇数位同理相加即可！

## 算法步骤 (Algorithm Steps)

* **分离奇偶下标**：遍历字符串 $a$ 和 $b$，分别收集偶数下标（$0, 2, 4, \dots$）上字符 `1` 出现的下标序列 $A_{\text{even}}, B_{\text{even}}$，以及奇数下标（$1, 3, 5, \dots$）上字符 `1` 出现的下标序列 $A_{\text{odd}}, B_{\text{odd}}$。
* **合法性判定**：检查 $\vert{}A_{\text{even}}\vert{} = \vert{}B_{\text{even}}\vert{}$ 且 $\vert{}A_{\text{odd}}\vert{} = \vert{}B_{\text{odd}}\vert{}$ 是否同时成立；若任意一个不相等，说明 `1` 的奇偶分布不守恒，直接输出 `-1`。
* **计算最少交换步数**：由于同奇偶子序列内每次操作将 `1` 在原串中的下标移动 $\pm 2$（即子序列内移动 $\pm 1$），按顺序一一配对同奇偶的 `1`，累加 $\frac{\vert{}A_{\text{even}}[j] - B_{\text{even}}[j]\vert{}}{2}$ 与 $\frac{\vert{}A_{\text{odd}}[j] - B_{\text{odd}}[j]\vert{}}{2}$。
* **输出结果**：累加得到的总步数即为将 $a$ 转化为 $b$ 的最少操作次数。

## 复杂度 (Complexity)

* **时间复杂度**：$\mathcal{O}(n)$（单次测试用例仅需线性扫描收集下标并线性求和，总时间 $\mathcal{O}(\sum n)$）。
* **空间复杂度**：$\mathcal{O}(n)$（用于存储奇偶位置的下标列表；若使用双指针在线匹配可进一步优化至 $\mathcal{O}(1)$ 额外空间）。

## 触发信号 (Trigger Signals)

* **多种局部子串替换规则互补**：题目给出若干长度固定的局部替换（如 `001`$\leftrightarrow$`100` 与 `110`$\leftrightarrow$`011`），穷举中间字符的所有取值后发现规则恰好拼合成无条件跨越交换（$s_i \leftrightarrow s_{i+k}$）。
* **固定步长跳跃与奇偶解耦**：操作只改变相距为 $2$（或固定步长 $k$）的两个位置，立即考虑按**下标模 $2$（或模 $k$）分组拆成独立子序列**。
* **`01` 串相邻交换求最小步数**：子序列内等价于相邻字符交换时，无需建图搜索，直接利用同种字符相对顺序不变（贪心保序匹配）计算下标差之和。
