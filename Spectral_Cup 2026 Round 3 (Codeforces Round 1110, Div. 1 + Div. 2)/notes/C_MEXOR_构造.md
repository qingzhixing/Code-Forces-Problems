# C. MEXOR

## 题目信息

* **Clist Rating**: 1362
* **算法标签**：构造、位运算、MEX

## 一句话题意

给定整数 $n$ 和 $k$，构造一个 $0 \sim n-1$ 的排列 $p$，使得所有前缀的 $\operatorname{mex}$ 的按位异或和等于 $k$；若无解则输出 `NO`。

## 我的第一思路

最初误以为题目要求的是前缀 $\operatorname{mex}$ 的**求和**而非**按位异或**，并且将排列的值域误记为 $1 \sim n$（推出 $f(n-1) = n+1$），从而试图利用 $f$ 单调不降的性质以及等差数列的上下界去凑 $k - n - 1$，方向与题意不符。

## 关键观察/转化

* 任意 $0 \sim n-1$ 的排列最后一个前缀的 $\operatorname{mex}$ 恒为 $f(n-1) = n$，两边同时异或 $n$ 可将目标简化为令前 $n-1$ 个前缀 $\operatorname{mex}$ 的异或和等于 $K' = k \oplus n$。
* 在 $0$ 出现之前，所有前缀的 $\operatorname{mex}$ 均为 $0$，对异或和没有任何贡献；因此只需把 $0$ 放在靠近末尾的位置，用最后 $1 \sim 3$ 个元素即可精确凑出 $K'$。
* 任意真前缀的 $\operatorname{mex}$ 不超过 $n-1$，因此能异或出的二进制最高位不会超过 $n-1$ 的最高位（MSB）。当 $K' > n-1$ 且与 $n-1$ 最高位相同时，令 $v = (n-1) \oplus K'$，最高位抵消后必然满足 $1 \le v < n-1$。

## 算法步骤

* 计算目标异或值 $K' = k \oplus n$。
* 若 $K' = 0$：将 $0$ 放在最后一位，其余数 $1 \sim n-1$ 放前面，使前 $n-1$ 个前缀的 $\operatorname{mex}$ 全为 $0$。
* 若 $1 \le K' \le n-1$：将末尾两位设为 $[0, K']$，其余数放前面，此时仅 $f(n-2) = K'$ 非零。
* 若 $K' > n-1$：比较 $K'$ 与 $n-1$ 的二进制最高位（MSB），若 $K'$ 的最高位严格更高（含 $n=1$ 的情况）则直接输出 `NO`；否则令 $v = (n-1) \oplus K'$，将末尾三位设为 $[0, v, n-1]$，其余数放前面，使得 $f(n-3) = v$ 且 $f(n-2) = n-1$，两者异或刚好为 $K'$。

## 复杂度

* **时间复杂度**：单组测试 $O(n)$，总时间复杂度 $O(\sum n)$。
* **空间复杂度**：$O(1)$（不计输入输出缓冲）。

## 我的卡点与错误点

* **审题与定义偏差**：一开始把异或和（$\oplus$）看成了加法求和，并把 $0 \sim n-1$ 排列的整体 $\operatorname{mex}$ 误算成 $n+1$。
* **位运算高低位混淆**：在 Rust 实现中判无解时误用了取最低位 $1$ 的 `lowbit(x)`，导致既会漏判无解也会误判有解；实际应比较二进制最高位 $1$（`highest_bit`），在 Rust 中可用 `leading_zeros()` 或 `ilog2()` 在 $O(1)$ 内实现。

## 触发信号

* 见到「排列构造 + 前缀 MEX」**：优先考虑**控制 $0$ 出现的位置，利用 $0$ 之前前缀 $\operatorname{mex}$ 全为 $0$ 的性质屏蔽多余项，只操纵末尾少数元素。
* 见到「用不超过 $M$ 的若干数异或凑出目标值 $K'$」：优先检查 $K'$ 的二进制最高位（MSB）是否超过 $M$；若未超过且 $K' > M$，可用 $M \oplus K'$ 消去最高位，得到一个严格小于 $M$ 的数来配合构造。
