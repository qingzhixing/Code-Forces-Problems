# C1. Disgusting + GCD (Constructive Version)

## 题目信息

Clist Rating: 1235

算法标签：数论 构造 贪心 数学

## 题目大意

给定一个长度为 n > 2 的正整数数组 a，ai > 2，要求在进行操作之后，其中任意两元素 ai, aj，满足 gcd(ai, aj) == 1 或者 min(ai, aj)。

操作：选择一个元素 ai，给它加上一个 与 ai 互斥的正整数 x。

限制：最多操作 n+10 次，增量 x 的总和不能超过原 a 数组元素和。

## 解题思路

* gcd(ai, aj) == 1 或者 min(ai, aj)，即两元素 要么 互斥 要么 其中一个能整除另一个。
* 不难发现，要满足任意元素互斥，那么 ai 每个元素都是质数满足这一条件。
* x 之和 不超过 a 之和，最多操作 n+10 次，可以转化为更严格的条件，对于数字 ai，使之变为最近的大于 ai 的质数，且增量 < ai，并且与之互斥。
* 这样，不同的数字总是互斥，重复数字之间能互相整除。

## 算法证明

我们目前要解决的问题是：数字 ai，使之变为最近的大于 ai 的质数，且增量 < ai，并且与之互斥。

### 伯特兰公设

> **伯特兰公设（Bertrand's postulate）**：对任意整数 $n>1$，在 $n$ 和 $2n$ 之间一定存在一个质数，即存在质数 $p$ 满足
>
> $$
> n<p<2n.
>
> $$

设 $q$ 是大于 $n$ 的最小质数，则 $q\le p<2n$。于是需要加上的数是

$$
k=q-n.

$$

因为 $q<2n$，所以

$$
k=q-n<n\le n.

$$

也就是说，加上的数一定小于 $n$，当然满足“$\le n$”。

### 增量互斥性证明

增量 x = q - n，一定与 n 互斥，用反证法证明：

设 d = gcd(x, n)，d > 1。

因为 d | x，且 d | n，故 d | (x+n)，即 d | q，但是 q 为质数，d 只能为 1 或者 q。

又因为 $0<x<q$，所以 $d \le x<q$，不可能等于 $q$。矛盾。
所以只能有 $d=1$，即 $n$ 与 $x$ 互质。

## 算法思路

1. 线性筛预处理 0 ~ 2 * MAX_N 的所有质数
2. 对于每一个 ai，在这个质数数组中二分查找第一个 >= ai  的质数并输出。
3. 对于不同数字，他们总是互质的，对于重复出现的相同数字，他们能互相整除，也满足条件。

## 复杂度

 时间复杂度：线性筛 O(n) + 每一个数二分 O(n log n) = O(n log n)

空间复杂度：O(n)

## 卡点

这题 rust 代码中 static 写成了 const ，const 实际上在 rust 中是个 constexpr，每次使用都内联求值，导致重复计算了质数数组 n 次，复杂度来到了 O(n^2 log n)。

## 触发点 (Triggers)

* **特征 1：全局两两互质要求 $\to$ 联想到「转化为质数」**
  * **题面关键字**：任意两元素满足 `gcd(ai, aj) == 1` 或 `min(ai, aj)`。
  * **条件反射**：要求一大堆数字两两互斥，最强的充分条件就是**它们全都是质数**。因为不同质数之间的 gcd 永远是 1。
* **特征 2：增量 $\le$ 原值 $\to$ 联想到「伯特兰-切比雪夫定理」**
  * **题面关键字**：增量 $x$ 的总和不能超过原数组元素和（即平均每次操作的增量 $x < a_i$）。
  * **条件反射**：要在小于自身大小的步数内找到一个质数，必然依赖 **伯特兰公设**（$n$ 到 $2n$ 之间必有质数）。只要题目涉及“找最近的质数且距离不能太远”，立刻思考该定理能否兜底。
* **特征 3：构造互质增量 $\to$ 联想到「反证法与整除性质」**
  * **题面关键字**：加上的数 $x$ 必须与原数 $a_i$ 互质（即 $\gcd(x, a_i) = 1$）。
  * **条件反射**：若目标是质数 $q = x + a_i$，则 $\gcd(x, a_i)$ 必然整除 $q$。由于 $q$ 是质数且 $x < q$，最大公约数只能是 1。这也是数论构造题中证明互质的常用套路。
* **特征 4 (Rust 工程踩坑)：预处理大数据 + TLE $\to$ 联想到「`static` 与 `const` 的误用」**
  * **题面关键字**：Rust 提交，算法复杂度正确却 TLE。
  * **条件反射**：检查带锁延迟初始化（如 `LazyLock` / `OnceLock`）或大数组是否被声明为了 `const`。`const` 会在每次调用处内联展开并重新求值，必须换成 `static` 才能实现真正的单例缓存。同时检查是否使用了 `BufWriter` 缓冲输出。
