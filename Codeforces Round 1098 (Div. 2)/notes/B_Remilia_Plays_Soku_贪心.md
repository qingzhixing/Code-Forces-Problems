# B. Remilia Plays Soku

## 题目信息

Clist Rating: 1002

算法标签：博弈论 模拟 贪心

## 题目大意

一个“环形跑道上的回合制抓捕游戏”，规则如下：

* **地图** ：**$n$** 个格子的环形跑道。
* **回合** ：每秒为一回合，蕾米莉亚先动，灵梦后动（每次只能移动 1 格或不动）。
* **限制** ：逃跑方（蕾米莉亚）整局游戏 **最多只能跑 **$k$** 步** ，抓人方（灵梦）步数无限。
* **问题** ：双方都绝对聪明（一个想尽早抓，一个想拼命拖），求抓到人需要的 **总回合数** 。

## 题目思路

- 可以发现，当 n <= 3 时，无论怎样都只需要一回合就能抓捕成功。（我的错误点）
- 如果 n >= 4，贪心地，可以沿着两点最短的那条弧追，你追我跑，距离不变。直到追了 k 格，被追的人就不能动了，剩下的距离还是两点之间的 劣弧长。答案为 k + min(dist, n - dist)，其中 dist = abs(x1 - x2);

## 错误点

忽略了小样例的特殊情况。
