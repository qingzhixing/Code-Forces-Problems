# E. Avalanche

## 题目信息 (Problem Info)

* **Clist Rating**: 1322
* **算法标签**：博弈论、不变量与势能分析、异或差分、树状数组、周期性规律

## 一句话题意 (One-Sentence Summary)

一排有 $n$ 堆石子，Alice 和 Bob 轮流任选非空堆 $i$ 取走 $1$ 颗石子，并向其左侧紧邻的至多 $k$ 个石子堆各加 $1$ 颗石子，无法操作者判负，求双方最优策略下的赢家。

## 我的第一思路 (Initial Approach)

发现操作只向左侧传递且总步数奇偶性固定后，直接从右往左逐堆模拟清空：若当前堆为奇数，则累计 $1$ 步有效操作并将左侧区间 $[\max(0, i - k), i)$ 的奇偶性整体取反。借助异或差分树状数组（`XorFenwick`）维护区间奇偶翻转与单点查询，虽然以 $\mathcal{O}(n \log n)$ 顺利通过，但带着具体输入数据硬模拟掩盖了底层的数学规律，实际上无需任何数据结构即可 $\mathcal{O}(n)$ 极简求解。

## 关键观察/转化 (Key Observations/Transformations)

* **拆解单石子贡献与势能守恒**：因石子裂变互不干扰，设 0-indexed 下单颗石子产生的总步数为 $f_i = 1 + \sum_{j=\max(0, i-k)}^{i-1} f_j$。任意合法操作均使总势能 $\Phi = \sum a_i f_i$ 严格减 $1$ 直至归零，故总步数恒为初始 $\Phi$，胜负仅取决于其奇偶性。
* **从“带数据倒推”转为“求单位系数”**：与其从右往左带着杂乱的 $a_i$ 用数据结构动态维护翻转，不如反向提取每个位置的单位奇偶权重 $g_i = f_i \bmod 2$，转化为定长窗口异或递推 $g_i = 1 \oplus \bigoplus_{j=\max(0, i-k)}^{i-1} g_j$。
* **滑动窗口抵消导出 $(k+1)$ 周期**：初始 $g_0 = 1$；当 $1 \le i \le k$ 时窗口内恰含一个 $g_0 = 1$，与开头的 $1$ 异或抵消得 $0$；当 $i = k + 1$ 时 $g_0$ 滑出窗口，全 $0$ 窗口使 $g_{k+1}$ 重回 $1$。故 $g$ 呈 $1$ 个 $1$ 后跟 $k$ 个 $0$ 的 $(k+1)$ 周期，仅 $i \bmod (k + 1) = 0$ 处的石子堆对胜负有贡献。

## 算法步骤 (Algorithm Steps)

* **读取规模参数**：读入石子堆数 $n$ 与裂变跨度 $k$，初始化有效步数的奇偶异或累加器 `xor_sum = 0`。
* **按周期筛选累加**：按 0-indexed 顺序遍历下标 $i = 0 \dots n - 1$ 并以 64 位整数读入 $a_i$；仅在满足 `i % (k + 1) == 0` 时执行 `xor_sum ^= a_i & 1`，其余位置直接跳过。
* **判定赢家输出**：遍历结束后，若 `xor_sum == 1` 输出 "Alice"，否则输出 "Bob"。

## 复杂度 (Complexity)

* **时间复杂度**：$\mathcal{O}(n)$，单组数据仅需一次线性扫描与常数级位运算，相比初始树状数组做法的 $\mathcal{O}(n \log n)$ 彻底消除了对数因子与建树开销。
* **空间复杂度**：$\mathcal{O}(1)$，支持流式边读边算，无需开辟原数组或差分树空间。

## 我的卡点与易错点 (Common Pitfalls & Mistakes)

* **过早陷入数据结构模拟**：看到“区间奇偶取反 + 单点查询”容易条件反射套用树状数组，忽略了翻转窗口长度恒为 $k$ 且单向推进的特殊性，错失提取单位权重 $g_i$ 直接找规律的降维机会。
* **下标基准与取模偏移错位**：周期判定式 `i % (k + 1) == 0` 建立在 0-indexed 基准上（保证最左端首堆必为有效堆）；若循环采用 1-indexed，条件必须同步调整为 `(i - 1) % (k + 1) == 0`。
* **读入数值类型溢出**：虽然运算只需最低位奇偶性，但原题 $a_i \le 10^9$，Rust 中切忌直接调用 `next::<u8>()` 解析输入，必须先用 `u64` 或 `i64` 读入后再做 `& 1` 截断。

## 触发信号 (Trigger Signals)

* **看到“博弈允许任选位置，且每次消耗 1 个单位并向单侧衍生新状态”**：优先定义单元素贡献函数 $f_i$ 验证每步总势能是否恒定减 $1$，确认步数与策略无关后立即放弃博弈搜索。
* **看到“线性可加过程的最终奇偶性问题”**：不要急于带着初始数组 $a_i$ 上数据结构模拟，先单独列出单位元素的模 $2$ 递推式 $g_i$，脱离不规则输入数据的干扰观察系数规律。
* **看到“定长滑动窗口异或加 1 递推（$g_i = 1 \oplus \bigoplus_{j=i-k}^{i-1} g_j$）”**：立刻手算前 $k + 2$ 项验证首个 $1$ 滑出窗口时的跳变效应，直接锁定 $(k + 1)$ 周期循环节。
