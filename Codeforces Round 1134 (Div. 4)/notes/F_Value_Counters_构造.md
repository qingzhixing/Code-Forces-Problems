# F. Value Counters

## 题目信息 (Problem Info)

* **Clist Rating**: 1666
* **算法标签**：数学、构造、排列性质、不变量消元

## 一句话题意 (One-Sentence Summary)

对于长度为 $n$ 的排列 $p$，每个数值 $x$ 的计数器 $b_x$ 等于其左侧比它小的元素个数减去右侧比它大的元素个数；给定数组 $b_1, \ldots, b_n$，要求还原出对应的排列 $p$ 或判定无解。

## 关键观察/转化 (Key Observations/Transformations)

* **贡献拆解**：只有满足 $x < y$ 且 $x$ 在 $y$ 左侧的顺序对才会改变计数器，因此对任意数值 $x$，其最终计数值恰好为 $b_x = L_{<x} - R_{>x}$（左侧更小元素数减去右侧更大元素数）。
* **四象限自由度消元**：在长度为 $n$ 的排列中，任意数值 $x$（设其所在位置下标为 $q_x \in [1, n]$）周围的四个局部统计量 $L_{<x}, L_{>x}, R_{<x}, R_{>x}$ 受全局大小和位置总数的强约束，自由度只有 $1$。设左侧比 $x$ 大的元素有 $\ell$ 个，则：
* 左侧共有 $q_x - 1$ 个元素，故 $L_{<x} = q_x - 1 - \ell$；
* 全局共有 $n - x$ 个比 $x$ 大的元素，故 $R_{>x} = n - x - \ell$；
* 两式相减，$\ell$ 完美抵消，得到恒等式 $b_x = q_x + x - n - 1$。
* **唯一性与充要性**：移项可得数值 $x$ 的唯一目标位置 $q_x = b_x + n + 1 - x$。由于上述恒等式对任意真实排列均无条件成立，只要所有 $q_x$ 均落在 $[1, n]$ 内且两两不同，按 $p_{q_x} = x$ 构造出的排列就必然还原出原数组 $b$，无需再用树状数组二次验证。

## 算法步骤 (Algorithm Steps)

* 读入当前测试组长度 $n$ 及完整数组 $b_1, b_2, \ldots, b_n$，创建长度为 $n + 1$ 的结果数组 $p$ 并初始化为空。
* 遍历每个数值 $x \in [1, n]$，利用公式计算该数值在排列中的目标下标 $q_x = b_x + n + 1 - x$。
* 校验位置合法性：若 $q_x < 1$ 或 $q_x > n$（越界），或者 $p_{q_x}$ 已经有值（位置冲突），直接输出 `-1` 并结束当前测试组。
* 否则令 $p_{q_x} = x$；遍历结束后按位置下标 $1$ 到 $n$ 依次输出 $p_i$。

## 复杂度 (Complexity)

* **时间复杂度**：单组测试数据 $\mathcal{O}(n)$，总体 $\mathcal{O}(\sum n)$。
* **空间复杂度**：$\mathcal{O}(n)$，用于存储输入数组与构造出的排列。

## 触发信号 (Trigger Signals)

* 题目背景为 **$1 \sim n$ 的排列**，且定义在顺序对、逆序对或元素左右两侧大小关系的加减计数上。
* 题面明确指出“若解存在则唯一”，强烈暗示位置与数值之间存在可直接求解的确定性方程。
* 表达式中出现 $L_{<x} - R_{>x}$ 或 $L_{>x} - R_{<x}$ 这类主/副对角线偏序数量之差时，立刻设其中一个象限为未知数 $\ell$ 列方程消元。
